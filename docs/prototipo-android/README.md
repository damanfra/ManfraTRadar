# Protótipo original (mobile)

Primeiro rascunho das telas, feito antes de decidir por desktop (Windows/Linux).
Serviu de base visual para o app: paleta escura, azul `#6EA8FF` para ações, verde para seeders e laranja para leechers.

| Arquivo | Tela |
|---|---|
| `Main.dc.html` | Descobrir — lista "Em alta hoje" com filtros por categoria |
| `Downloads.dc.html` | Downloads — progresso, velocidades, pausar/retomar |
| `Detalhes.dc.html` | Detalhes do torrent — saúde do swarm, seleção de arquivos, download sequencial |

São componentes do editor de design do Claude (formato `.dc.html`). Não abrem sozinhos no navegador porque
dependem do runtime do editor; ficam aqui como referência de layout e conteúdo.
A seleção de arquivos da tela de detalhes ainda não existe no app desktop (está nos próximos passos do `CLAUDE.md`).
